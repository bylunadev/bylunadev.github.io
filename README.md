# Luana Menezes · Portfólio

Portfólio pessoal em português (Brasil), espanhol (Argentina) e inglês.

## Rodar no computador

```sh
npm install
npm run dev
```

## Publicação

```sh
npm run deploy
```

Gera o site e envia para a branch `gh-pages`, que o GitHub Pages publica em
https://bylunadev.github.io
